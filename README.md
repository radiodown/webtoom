# 나의 웹툰

HTML, CSS, 순수 JavaScript로 만든 정적 웹툰 뷰어입니다. 별도 설치나 빌드가 필요하지 않습니다.

- **1화 · 클로드**: 5장, **2화 · 프라이데이**: 5장, **3화 · 컨텍스트 0%**: 9장을 회차별로 표시합니다.
- 1·2화는 접미사 없는 파일부터 `_01`, `_02`, `_03`, `_04` 순서로, 3화는 `1.png`부터 `9.png` 순서로 표시합니다.
- 상단 회차 선택 메뉴에서 이동하거나 `?episode=01`, `?episode=02`, `?episode=03` 주소로 바로 열 수 있습니다. 기본 화면은 최신 회차인 3화입니다.
- 이미지 사이 기본 간격은 **12px**, 기본 본문 너비는 **800px**입니다.
- 모바일에서는 화면 폭에 맞춰 이미지가 줄어들며 원본 비율을 유지합니다.
- 보기 설정에서 너비와 간격을 바꿀 수 있고 밝은 화면도 지원합니다.
- 설정과 읽던 이미지 위치는 브라우저에 저장됩니다. 재방문하면 ‘이어서 읽기’를 선택할 수 있습니다.
- 원본 이미지를 그대로 사용하며, 뒤쪽 이미지는 지연 로딩합니다.

## 바로 열기

`index.html`을 브라우저에서 여세요. 인터넷 연결이나 개발 서버 없이도 읽을 수 있습니다.

로컬 서버로 확인하려면 이 폴더에서 다음 명령을 실행하고 `http://localhost:8000`으로 접속하세요.

```powershell
python -m http.server 8000
```

## GitHub Pages 배포

1. GitHub 저장소를 만들고 이 폴더의 파일과 **이미지 폴더 전체**를 저장소 최상위에 올립니다. 숨김 파일인 `.nojekyll`도 포함하세요.
2. 저장소의 **Settings → Pages**에서 배포 소스를 **GitHub Actions**로 선택합니다.
3. `main`에 푸시하면 `.github/workflows/pages.yml`이 자동으로 배포합니다. **Actions → Deploy webtoon to GitHub Pages → Run workflow**로 직접 실행할 수도 있습니다.
4. 배포가 끝나면 `https://radiodown.github.io/webtoom/`으로 접속합니다.

모든 리소스가 상대 경로를 사용하므로 `https://계정.github.io/저장소이름/` 같은 프로젝트 주소에서도 동작합니다. 폴더명의 한글, 공백, `%`는 코드에서 URL 인코딩합니다.

## 새 회차 추가

새 회차 이미지 폴더를 만들고 `episodes.js` 배열 끝에 다음 형식의 항목을 추가하세요. 이미지는 **배열에 적은 순서대로** 표시되므로 `1, 2, …, 10` 순으로 직접 적습니다. 마지막 항목 뒤에 회차를 추가하면 새 회차가 기본으로 열립니다.

```javascript
{
  id: "04",
  title: "새 회차의 부제",
  folder: "04-새 회차의 부제",
  images: [
    { file: "1.png", width: 1054, height: 1492 },
    { file: "2.png", width: 1054, height: 1492 }
  ]
}
```

`width`, `height`에는 실제 이미지 크기를 넣으세요. 로딩 전에 공간을 확보해 읽던 위치가 흔들리는 것을 줄입니다. 회차 선택 메뉴는 등록한 회차만 표시합니다. `?episode=03`으로 특정 회차를 바로 열 수 있습니다.

사이트 이름은 `index.html`의 ‘나의 웹툰’, 기본 색상과 간격은 `styles.css`의 `:root`, 기본 보기 설정은 `app.js`의 `defaults`에서 수정할 수 있습니다.
